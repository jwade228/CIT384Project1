# CIT384Project1
A project website showing one of my favorite music festivals. I used iframes to embed specific songs that i like from each artist on the artist page. Used form, fieldset, input, and placeholder for the last page on the site where friends can sign up for the experience and give me information on how they want to proceed with their experience. On the about page I used images and attribute src on each section card.
